사용 방법

  1. POCKET MYTH를 설치하고 튜토리얼을 완료합니다.
  2. 트레이너 프로필에서 설정으로 이동합니다.
  3. 교환 코드 입력란에 코드를 붙여넣습니다.
  4. 확인 후 게임 우편함에서 보상을 받습니다.

대부분의 코드는 캐릭터당 한 번만 사용할 수 있습니다. 실패하면 철자, 서버, 이벤트 기간을 확인하세요.

교환 코드 FAQ

모든 서버에서 사용할 수 있나요?

대부분 그렇습니다. 일부 코드는 특정 서버나 지역 전용이며, 코드 아래 설명에 표시됩니다.

코드가 유효하지 않다고 나오는 이유는?

이벤트가 끝났거나 이미 사용한 캐릭터이거나, 해당 서버에서 쓸 수 없는 코드일 수 있습니다.

이 페이지는 얼마나 자주 갱신되나요?

새 코드가 확인될 때마다 갱신되며, 페이지 상단의 날짜가 마지막 확인 시점입니다.

코드는 게임 안에서 사용합니다. 먼저 POCKET MYTH를 설치하세요.
